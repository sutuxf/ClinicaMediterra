# 05-Hombres — Customer Research

Análisis específico de bloqueadores/motivadores para hombres.

## Fuentes

- [ ] Conversaciones con hombres (WhatsApp, DMs, llamadas)
- [ ] Reseñas de hombres en Google/Trustpilot
- [ ] Comentarios de hombres en Instagram
- [ ] Entrevistas directas (si se puede)
- [ ] No-shows de hombres (por qué no vuelven)

## Estructura de Archivos

```
05-hombres/
├── bloqueadores-tabu.md (vergüenza, estigma, identidad masculina)
├── motivadores-principales.md (qué los convence a venir)
├── frases-clave-hombres.md (cómo hablan del problema)
├── testimonios-anonimos.md (pacientes hombres reales)
└── SINTESIS-HOMBRES.md (estrategia de pauta + copy)
```

## Qué Buscar

- Palabras que evitan decir (vergüenza)
- Preocupaciones sobre confidencialidad
- Comparación con otros países/regiones
- Influencers/personajes que mencionan
- Cómo explicar sin jerga médica

**Propósito:** Informar pauta mensual, copy sin tabú, y estrategia de contenido educativo.
