# 04-No-Shows — Customer Research

Análisis de pacientes que agendaron pero no asistieron.

## Fuentes

- [ ] Reporte de no-shows de Medilink
- [ ] Llamadas de seguimiento (motivos)
- [ ] Análisis de patrones (día, hora, especialidad)
- [ ] Feedback de secretaria

## Estructura de Archivos

```
04-no-shows/
├── datos-no-shows-anonimos.md (fecha, hora, especialidad, edad aprox)
├── motivos-confirmados.md (olvido, vergüenza, horario, transporte)
├── patrones-identificados.md (qué grupos noshow más)
└── SINTESIS-NO-SHOWS.md (ROI de recordatorios)
```

## Qué Documentar

- Fecha y hora de agendamiento
- Fecha y hora de cita perdida
- Especialidad
- Motivo (si se confirmó)
- Género aproximado
- ¿Intentos de contacto previos?

---

**Propósito:** Cuantificar $9M/mes en pérdidas y validar ROI de agente recordatorios.
