## 🎯 MÉTRICAS DE ÉXITO

### **Métrica Principal: % Pacientes Hombres**

```
Baseline (hoy):           32%
Meta mes 3:               35% (+3%)
Meta mes 6:               40% (+8% del baseline)

Cálculo:
- 280 atenciones/mes actual
- 32% hombres = 90 hombres/mes
- Meta mes 2-3: +25 hombres nuevos (80K ads)
- Estimado: 115 hombres/mes = 35%
```

---

### **Métrica Secundaria: Cost Per Lead (CPL)**

```
CPL objetivo:            $500-1.000 CLP
(Si gasto $80K/mes en ads, quiero min. 80 leads nuevos)

Desglose:
- Semana 5: CPL $2.000 (awareness, no es lead)
- Semana 6: CPL $1.500 (retargeting, empiezan a interesar)
- Semana 7-8: CPL $400 (hot audience, listo para agendar)
```

---

### **Métrica Tertiary: Appointments Booked**

```
Meta: 40 nuevas consultas/mes de hombres
Cálculo:
- CPL $800 promedio → $80K = 100 leads
- Conversion lead→appointment: 40% = 40 appointments
- Show rate: 75% = 30 consultas realizadas
- Conversión consulta→paciente: 80% = 24 pacientes nuevos/mes
```
